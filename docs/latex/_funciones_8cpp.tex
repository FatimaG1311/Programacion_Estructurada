Menu de funciones especiales.
\begin{DoxyItemize}
\item Se muestra un menú con las funciones especiales disponibles (Triangular, Gamma, Trapezoidal y Función S) y se le pide al usuario seleccionar la función que desea calcular ingresando el número correspondiente (1, 2, 3 o 4).
\item Se utiliza la función scanf para almacenar el valor ingresado por el usuario en la variable Op, que se utilizará posteriormente para determinar qué función calcular.
\item \texorpdfstring{$\ast$}{*} El menú se muestra utilizando la función printf, y se especifica que el usuario debe ingresar un número del 1 al 4 para seleccionar la función deseada.
\end{DoxyItemize}

Case 1:\+ Realiza el cálculo de la función Triangular.
\begin{DoxyItemize}
\item Se solicitan al usuario los valores de x, a, m y b necesarios para el cálculo de la función Triangular.
\item Se utilizan estructuras de control if-\/else para evaluar las condiciones necesarias para calcular el resultado de la función Triangular, que se almacena en la variable result.
\item El resultado de la función se muestra al usuario utilizando la función printf, y se especifica que el resultado se muestra con dos decimales utilizando el formato \%.2f.
\item Break:\+ Se utiliza para salir del switch después de ejecutar el caso correspondiente, evitando que se ejecuten los casos siguientes de manera accidental. ~\newline

Función principal del programa. 


\begin{DoxyItemize}
\item Se definen las variables necesarias para el cálculo de las funciones especiales, incluyendo la variable Op para seleccionar la función a calcular, y las variables x, m, a, b, c, d y result para almacenar los valores de entrada y el resultado de la función.
\item \texorpdfstring{$\ast$}{*} Las variables x, m, a, b, c, d y result se definen como float (decimal) para permitir el ingreso de valores con decimales y para almacenar los resultados de las funciones que pueden ser decimales.
\item \texorpdfstring{$\ast$}{*} La variable Op se define como int (entero) para permitir la selección de la función a calcular mediante un menú de opciones.
